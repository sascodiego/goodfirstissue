# Procedencia del material

Este repositorio **no es un fork**. Contiene, además del código propio de
GoodFirstIssue, una copia del material original del **#2 Hackathon NaN**, tomado de
`https://github.com/helmcode/nan-hackathon-clef` en el commit `6999787`.

## Qué se copió y por qué

| Ruta | Origen | Motivo |
|---|---|---|
| `docs/api.md`, `docs/retos/` | repo del hackathon | contrato de la API de Clef y reglas del reto: son la autoridad del proyecto |
| `examples/` | repo del hackathon | ejemplos oficiales de invocación |
| `assets/banner.png` | repo del hackathon | imagen usada por el README original |
| `README.hackathon.md` | README del hackathon | se conserva **byte a byte**, con sus enlaces relativos funcionando |

El material se conserva **sin modificaciones** (`README.hackathon.md` es idéntico al
original) porque `PROYECTO.md` cita `docs/api.md` como contrato y porque la trazabilidad
del origen importa más que la prolijidad.

## Licencia del material copiado

El repositorio de origen **no declara ninguna licencia**. La ausencia de `LICENSE` no
concede derechos de forma automática, así que este material se mantiene aquí:

- como **referencia del hackathon** para el que fue publicado,
- **sin licencia propia declarada para él**,
- y **sin ninguna garantía**.

Si el equipo del hackathon publica una licencia, prevalece esa.

El código propio de GoodFirstIssue (todo lo que no está en la tabla de arriba) se rige
por el archivo `LICENSE` de este repositorio, si existe.
